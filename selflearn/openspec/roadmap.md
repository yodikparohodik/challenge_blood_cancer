# OpenSpec: План развития SelfLearn

## Версия 0.1 (MVP - текущая)

### Реализовано
- [x] Базовая архитектура с тремя модулями (Рефери, Учитель, Ученик)
- [x] Генерация синтетических страниц с текстовыми блоками
- [x] 9 типов искажений изображений
- [x] Простой эвристический классификатор
- [x] Цикл соревнований и раундов
- [x] Анализ слабых мест и передача фокуса Учителю
- [x] Web API для управления
- [x] Сохранение состояния и возобновление

### Метрики MVP
- Точность детекции "битых" данных: ~85-95%
- IoU сегментации: ~0.4-0.6 (базовый уровень)
- Время обработки: <100ms на изображение (CPU)

## Технические долги

1. **Синхронность**: Текущая реализация синхронная, требуется async/await для масштабируемости
2. **Хранение данных**: Перейти на SQLite/PostgreSQL вместо JSON файлов
3. **Очереди задач**: Добавить Celery/RQ для фоновых задач
4. **Кеширование**: Redis для кеширования предсказаний
5. **Версионирование моделей**: MLflow илиWeights & Biases

## Риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Недостаточно данных | Средняя | Высокое | Синтетическая генерация, transfer learning |
| Переобучение на синтетике | Высокое | Среднее | Domain adaptation, смешанные данные |
| GPU память | Средняя | Среднее | Gradient accumulation, mixed precision |
| Дрейф данных | Низкая | Высокое | Continuous monitoring, retraining triggers |
