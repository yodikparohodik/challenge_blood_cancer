# SelfLearn - Автономная система самообучения

Система самообучения для классификации, сегментации и описания медицинских изображений с адаптивной генерацией данных.

## Архитектура

Система состоит из трех взаимодействующих модулей:

1. **Модуль Рефери** (`referee.py`) - оркестратор цикла обучения
   - Управляет соревнованиями и раундами
   - Собирает статистику по результатам
   - Анализирует слабые места Ученика
   - Передает фокус Учителю для адаптивной генерации

2. **Модуль Учитель** (`teacher.py`) - генератор учебных данных
   - Генерирует синтетические страницы с разметкой
   - Применяет искажения (засветка, шум, деформации и др.)
   - Адаптируется под слабые места Ученика
   - Создает "битые" данные для обучения детекции брака

3. **Модуль Ученик** (`student.py`) - модели и обучение
   - Предсказывает классификацию, сегменты, описания
   - Обучается на данных от Учителя
   - Выбирает лучшую модель по результатам валидации
   - Анализирует ошибки для передачи фокуса

## Установка

```bash
cd selflearn
pip install -r requirements.txt
```

## Быстрый старт

### Тестовый запуск
```bash
python run.py --action test
```

### Полный цикл обучения
```bash
python run.py --action run --competitions 3 --rounds 5 --tasks 10
```

### Запуск веб-API
```bash
python run.py --action api --port 8000
```

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/` | Статус сервиса |
| GET | `/status` | Текущее состояние системы |
| GET | `/results` | Результаты обучения |
| POST | `/train` | Запустить обучение |
| POST | `/admin/reset` | Сброс состояния |

## Типы искажений

Система поддерживает следующие виды искажений:
- **overexpose** - засветка
- **darken** - затемнение
- **noise** - гауссов шум
- **blur** - размытие
- **fade** - непропечатанный текст
- **vignette** - виньетка (темные края)
- **trapezoid** - трапецеидальная деформация
- **fisheye** - эффект рыбьего глаза
- **jpeg** - JPEG-артефакты

## Конфигурация

### referee.yaml
```yaml
base_dir: ./data/referee
num_competitions: 3
rounds_per_competition: 5
tasks_per_round: 10
training_epochs: 2
```

### teacher.yaml
```yaml
base_dir: ./data/teacher
broken_probability: 0.02
max_batch_size: 20
```

### student.yaml
```yaml
base_dir: ./data/student
models:
  - name: simple_classifier
    type: simple
```

## Возобновление после сбоя

Система автоматически сохраняет состояние после каждого раунда. Для возобновления:
```bash
python run.py --action status  # Проверка состояния
python run.py --action run     # Автоматическое возобновление
```
