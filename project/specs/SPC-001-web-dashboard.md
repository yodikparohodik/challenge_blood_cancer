# OpenSpec: SPC-001 - Веб-интерфейс Dashboard

## Статус: VERIFY

### 1. Цель
Создать базовый веб-интерфейс для визуализации процесса самообучения системы SelfLearn в реальном времени.

### 2. Требования
- **Функциональные**:
  - Отображение текущей статистики обучения (раунд, задача, точность)
  - График прогресса обучения по раундам
  - Список активных моделей с их параметрами
  - Кнопки управления (Старт, Стоп, Сброс)
  - Лог событий в реальном времени
- **Технические**:
  - HTML5 + Vanilla JS (без тяжелых фреймворков)
  - Автообновление данных каждые 2 секунды через API
  - Адаптивный дизайн (mobile-first)
  - Интеграция с FastAPI backend (`/status`, `/results`, `/models`)

### 3. План реализации (PIVDA)
1. **Plan**: Создать эту спецификацию ✅
2. **Implement**: 
   - Создать `static/html/pages/dashboard.html`
   - Создать `static/js/app/dashboard.js`
   - Обновить `src/selflearn/api.py` для отдачи статики
3. **Verify**: Протестировать запуск сервера и открытие страницы
4. **Document**: Обновить USER_GUIDE.md разделом про веб-интерфейс
5. **Archive**: Переместить спецификацию в `specs/archive/`

### 4. Критерии приемки
- [ ] Страница открывается по адресу `http://localhost:8000/`
- [ ] Данные обновляются автоматически без перезагрузки
- [ ] Интерфейс корректно отображается на мобильных устройствах
- [ ] Кнопки управления отправляют запросы к API
