# SelfLearn - Автономная система самообучения

## 📖 Описание для пользователя

SelfLearn — это полностью автономная система самообучения, которая генерирует собственные обучающие данные, тренирует модели и адаптирует сложность задач на основе результатов. Система работает по принципу "учитель-ученик-рефери", где:

- **Учитель (Teacher)** создаёт задачи с искажениями разной сложности
- **Ученик (Student)** решает задачи и обучается на ошибках
- **Рефери (Referee)** управляет процессом, оценивает результаты и адаптирует стратегию

### 🔧 Установка

```bash
cd /workspace/src/selflearn
pip install -r requirements.txt
```

### 🚀 Быстрый старт

#### 1. Тестовый запуск (проверка работоспособности)
```bash
python run.py --action test
```
Запускает 1 соревнование с минимальными параметрами для проверки системы.

#### 2. Полноценное обучение
```bash
python run.py --action run --competitions 5 --rounds 10 --tasks 50
```
- `--competitions`: количество полных циклов обучения (по умолчанию 3)
- `--rounds`: раундов в каждом соревновании (по умолчанию 5)
- `--tasks`: задач для генерации в каждом раунде (по умолчанию 20)

#### 3. Запуск веб-сервера (API)
```bash
python run.py --action api --port 8000
```
После запуска API доступен по адресу `http://localhost:8000`

**Доступные endpoints:**
- `GET /status` — текущее состояние системы
- `GET /results` — результаты всех соревнований
- `GET /models` — список доступных моделей
- `POST /train` — запустить обучение (параметры в JSON)
- `POST /admin/reset` — сбросить все результаты
- `POST /admin/stop` — остановить текущее обучение

### 📁 Структура данных

Все данные сохраняются в папке `data/`:
- `state.json` — текущее состояние системы (автосохранение после каждого раунда)
- `results.json` — история всех соревнований
- `generated/` — сгенерированные изображения задач
- `models/` — сохранённые веса моделей

### ⚙️ Конфигурация

Файлы конфигурации находятся в `config/`:
- `default.yaml` — основные настройки системы
- `degradations.yaml` — параметры искажений
- `models.yaml` — архитектуры моделей

Пример изменения конфигурации:
```yaml
# config/default.yaml
system:
  seed: 42
  log_level: INFO
  
training:
  batch_size: 32
  learning_rate: 0.001
  epochs: 10
```

### 🎯 Как это работает

1. **Генерация данных**: Учитель создаёт изображения с цифрами/фигурами и применяет случайные искажения (шум, размытие, окклюзии и т.д.)

2. **Решение задач**: Ученик (нейросеть) пытается распознать содержимое изображений

3. **Оценка**: Рефери сравнивает предсказания с правильными ответами, вычисляет метрики (accuracy, F1-score)

4. **Адаптация**: На основе ошибок система увеличивает долю тех типов искажений, которые вызывают больше всего проблем

5. **Сохранение прогресса**: После каждого раунда состояние сохраняется — можно остановить и продолжить позже

### 📊 Просмотр результатов

После обучения результаты доступны:
- В файле `data/results.json`
- Через API endpoint `/results`
- В логах консоли (при запуске с `--log-level DEBUG`)

### 🛠️ Расширенные возможности

#### Возобновление прерванного обучения
Система автоматически обнаруживает предыдущее состояние и продолжает с места остановки:
```bash
python run.py --action run --competitions 10
```

#### Кастомные модели
Добавьте свою архитектуру в `config/models.yaml` и укажите её имя при запуске.

#### Экспорт данных
Все сгенерированные изображения сохраняются в `data/generated/` с метаданными в JSON.

### ❓ Часто задаваемые вопросы

**Q: Сколько времени занимает обучение?**  
A: Зависит от параметров. Тестовый запуск (~1 мин), полноценное обучение (5-30 мин на обычном CPU).

**Q: Можно ли использовать GPU?**  
A: Да, система автоматически использует CUDA если доступна (требуется torch с поддержкой GPU).

**Q: Как сбросить все результаты?**  
A: Удалите папку `data/` или вызовите `POST /admin/reset` через API.

**Q: Где посмотреть логи?**  
A: Логи выводятся в консоль. Для сохранения в файл добавьте `--log-file training.log`.
