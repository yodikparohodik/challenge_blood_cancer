## 📋 Описание директорий

### `/src/selflearn/` - Исходный код
Основная библиотека SelfLearn. Содержит все модули системы:
- **common.py** - Базовые утилиты, метрики, константы
- **degrade.py** - 9 типов искажений изображений
- **synthesize.py** - Генерация синтетических данных
- **teacher.py** - Генерация задач с адаптацией
- **student.py** - Нейронные сети и обучение
- **referee.py** - Управление циклом обучения
- **api.py** - REST API сервер
- **run.py** - CLI интерфейс

### `/static/html/` - HTML файлы
Веб-интерфейс системы, сгруппированный по типам страниц:
- **pages/** - Полноценные страницы (dashboard, settings, etc.)
- **components/** - Переиспользуемые компоненты (headers, cards, tables)
- **admin/** - Административный интерфейс
- **api/** - Страницы документации API

### `/static/js/` - JavaScript файлы
Клиентская логика веб-интерфейса:
- **app/** - Основные приложения (dashboard.js, monitoring.js)
- **components/** - UI компоненты на JS
- **utils/** - Вспомогательные функции (api.js, formatters.js)

### `/config/` - Конфигурация
YAML файлы настройки системы:
- **default.yaml** - Основные параметры (seed, batch_size, epochs)
- **degradations.yaml** - Параметры искажений (severity ranges)
- **models.yaml** - Архитектуры моделей, hyperparameters

### `/data/` - Данные
Автоматически создаваемая директория для:
- Сгенерированных изображений
- Сохранённых моделей
- Результатов обучения (JSON)
- Состояния системы (state.json)

### `/docs/` - Документация
Пользовательская документация в свободном формате:
- **USER_GUIDE.md** - Подробное руководство для пользователей
- **README.md** - Быстрый старт и обзор
- Дополнительные руководства и FAQ

### `/specs/` - Спецификации OpenSpec
Техническая документация разработки:
- **template.md** - Шаблон для новых спецификаций
- **OPENSPEC-RULE-001.md** - Правило PIVDA процесса
- **archive/** - Завершённые спецификации

### `/tests/` - Тесты
Автоматизированные тесты:
- Unit тесты для каждого модуля
- Integration тесты полного цикла
- API тесты endpoints

## 🔧 Правила организации кода

### Python модули
- Один класс/функция на файл (если возможно)
- Docstrings для всех публичных API
- Type hints для всех функций
- Импорт из `src/selflearn/` через относительные пути

### HTML файлы
- Группировка по уровням: pages > components
- Инлайн CSS только для критических стилей
- Подключение JS через `<script src="...">`

### JavaScript файлы
- ES6+ синтаксис
- JSDoc комментарии для публичных функций
- Модульная структура (import/export)

### Конфигурации
- YAML формат
- Комментарии для всех параметров
- Значения по умолчанию в default.yaml

### Спецификации
- Формат имени: `SPC-XXX-description.md`
- Обязательные разделы: Plan, Implement, Verify, Document, Archive
- Статусы: Draft → Approved → In Progress → Verified → Documented → Archived

## 📊 Масштабирование структуры

При росте проекта:

```
/src/
  ├── selflearn/          # Ядро системы
  ├── extensions/         # Плагины и расширения
  ├── integrations/       # Интеграции с внешними системами
  └── experiments/        # Экспериментальные функции

/static/
  ├── css/               # Вынести CSS в отдельную папку
  ├── images/            # Статические изображения
  └── fonts/             # Шрифты

/docs/
  ├── user/              # Пользовательские руководства
  ├── developer/         # Документация для разработчиков
  └── api/               # API документация

/specs/
  ├── features/          # Спецификации функций
  ├── bugs/              # Спецификации исправлений
  └── rfc/               # Request for Comments
```
