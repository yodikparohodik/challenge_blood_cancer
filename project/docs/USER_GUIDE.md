## Введение

**SelfLearn** — это автономная система самообучения искусственного интеллекта, которая не требует участия человека в процессе обучения. Система самостоятельно генерирует обучающие данные, обучает модели, оценивает результаты и адаптирует сложность данных на основе успехов и ошибок модели.

### Ключевые возможности

✅ **Полная автономность** — система работает без вмешательства человека  
✅ **Адаптивная сложность** — автоматически подстраивается под слабые места модели  
✅ **Сохранение прогресса** — можно остановить и возобновить обучение в любой момент  
✅ **Веб-интерфейс** — мониторинг прогресса через браузер  
✅ **Гибкая настройка** — конфигурационные файлы для тонкой настройки  

### Как это работает?

Система использует архитектуру **Teacher-Student-Referee**:

```
┌─────────────────────────────────────────┐
│           Referee (Судья)               │
│    Управляет всем процессом обучения    │
└───────────────┬─────────────────────────┘
                │
        ┌───────┴───────┐
        ▼               ▼
┌──────────────┐  ┌──────────────┐
│   Teacher    │  │   Student    │
│ (Учитель)    │  │ (Ученик)     │
│ Генерирует   │  │ Обучается    │
│ задачи       │  │ Решает задачи│
└──────────────┘  └──────────────┘
```

**Teacher (Учитель)** — создаёт изображения с цифрами и применяет к ним различные искажения (шум, размытие, повороты и т.д.)

**Student (Ученик)** — нейронная сеть, которая учится распознавать цифры на искажённых изображениях

**Referee (Судья)** — управляет процессом, оценивает успехи ученика и говорит учителю, какие типы задач нужно давать чаще

## Основные понятия

### Соревнование (Competition)
Полный цикл обучения, состоящий из нескольких раундов. После каждого соревнования сохраняется лучшая модель.

### Раунд (Round)
Один этап внутри соревнования. В каждом раунде:
1. Учитель генерирует задачи
2. Ученик решает их
3. Судья оценивает результаты
4. Учитель адаптируется

### Задача (Task)
Одно изображение с цифровой меткой. Изображение может содержать искажения одного или нескольких типов.

### Искажение (Degradation)
Применённое к изображению изменение. Доступно 9 типов:

| Тип | Описание | Пример |
|-----|----------|--------|
| `gaussian_noise` | Гауссов шум | "Зернистость" изображения |
| `salt_pepper` | Соль и перец | Чёрные и белые точки |
| `blur` | Размытие | Нечёткое изображение |
| `brightness` | Яркость | Слишком светло/темно |
| `contrast` | Контраст | Бледные или чрезмерно яркие цвета |
| `rotation` | Поворот | Изображение повёрнуто |
| `occlusion` | Окклюзия | Часть изображения закрыта |
| `compression` | Компрессия | Артефакты JPEG |
| `distortion` | Дисторсия | Геометрические искажения |

### Метрики
- **Accuracy** — точность (доля правильных ответов)
- **Precision** — точность положительных предсказаний
- **Recall** — полнота обнаружения
- **F1-Score** — гармоническое среднее precision и recall

## Использование

### Режимы работы

Система поддерживает три режима работы:

#### 1. Тестовый режим (`test`)

Быстрая проверка работоспособности:

```bash
python src/selflearn/run.py --action test
```

**Что происходит:**
- 1 соревнование
- 1 раунд
- 5 задач
- 2 эпохи обучения

**Когда использовать:**
- Первая установка
- Проверка после изменений
- Быстрая демонстрация

#### 2. Режим обучения (`run`)

Полноценное обучение модели:

```bash
python src/selflearn/run.py --action run \
  --competitions 5 \
  --rounds 10 \
  --tasks 50
```

**Параметры:**
- `--competitions N` — количество соревнований (по умолчанию 3)
- `--rounds N` — раундов в каждом соревновании (по умолчанию 5)
- `--tasks N` — задач в каждом раунде (по умолчанию 20)
- `--epochs N` — эпох обучения (из конфига или CLI)
- `--batch-size N` — размер батча (из конфига или CLI)

**Пример полного запуска:**

```bash
python src/selflearn/run.py --action run \
  --competitions 10 \
  --rounds 20 \
  --tasks 100 \
  --epochs 15 \
  --batch-size 64 \
  --log-level INFO \
  --log-file training.log
```

**Время обучения:**
- 1 competition × 5 rounds × 20 tasks ≈ 5-10 минут
- 10 competitions × 20 rounds × 100 tasks ≈ 2-4 часа

#### 3. Режим API сервера (`api`)

Запуск веб-сервера для мониторинга и управления:

```bash
python src/selflearn/run.py --action api --port 8000
```

После запуска откройте в браузере:
- **Статус системы**: http://localhost:8000/status
- **Результаты**: http://localhost:8000/results
- **Документация API**: http://localhost:8000/docs

**Ответ:**

```json
    "current_competition": 2,

  }
```

#### GET /results
Получить все результаты соревнований

```bash
curl http://localhost:8000/results
```

#### GET /models
Получить информацию о доступных моделях

```bash
curl http://localhost:8000/models
```

Запустить обучение

```bash
curl -X POST http://localhost:8000/train \
  -H "Content-Type: application/json" \

    "rounds": 10,

    "epochs": 10,
    "batch_size": 32

```

Остановить текущее обучение

```bash
curl -X POST http://localhost:8000/admin/stop \
  -H "Content-Type: application/json" \
  -d '{"confirm": true}'
```

#### POST /admin/reset
Сбросить всё состояние системы

⚠️ **Внимание**: Это удалит все результаты и модели!

```bash
curl -X POST http://localhost:8000/admin/reset \
  -H "Content-Type: application/json" \
```

## Конфигурация

### Файлы конфигурации

Все конфиги находятся в директории `/workspace/project/config/`

#### default.yaml
Основной файл конфигурации:

```yaml
system:
  seed: 42              # Для воспроизводимости
  log_level: INFO       # Уровень логов
  data_dir: data        # Директория для данных
  save_every_round: true # Сохранять после каждого раунда

training:
  batch_size: 32        # Размер батча
  learning_rate: 0.001  # Скорость обучения
  epochs: 10            # Эпох по умолчанию
  optimizer: adam       # Оптимизатор
  patience: 5           # Early stopping

teacher:
  initial_degradation_probs:
    gaussian_noise: 0.11
    salt_pepper: 0.11
    blur: 0.11
    brightness: 0.11
    contrast: 0.11
    rotation: 0.11
    occlusion: 0.11
    compression: 0.11
    distortion: 0.12
  adaptation_rate: 0.1   # Скорость адаптации
  max_probability: 0.4   # Макс. вероятность типа
  min_probability: 0.05  # Мин. вероятность типа

student:
  model_type: SimpleCNN  # Тип модели
  num_classes: 10        # Классов (цифры 0-9)
  input_size: [64, 64, 3] # Размер входа
```

#### degradations.yaml
Настройки искажений:

```yaml
degradations:
  gaussian_noise:
    severity_range: [0.0, 0.5]
    params:
      mean: 0
      std_multiplier: [0.01, 0.5]
  
  blur:
    severity_range: [0.0, 1.0]
    params:
      kernel_size: [3, 15]
  
  # ... остальные типы
```

### Использование кастомного конфига

Создайте свой файл конфигурации:

```yaml
# config/my_config.yaml
system:
  seed: 123
  log_level: DEBUG

training:
  batch_size: 64
  epochs: 20
```

Запустите с конфигом:

```bash
python src/selflearn/run.py --action run --config config/my_config.yaml
```

## Часто задаваемые вопросы

### ❓ Сколько времени занимает обучение?

Зависит от параметров:
- **Тестовый режим**: 1-2 минуты
- **Малое обучение** (3×5×20): 15-30 минут
- **Среднее обучение** (10×20×50): 2-4 часа
- **Большое обучение** (50×50×100): 1-2 дня

### ❓ Где сохраняются результаты?

Все данные сохраняются в директории `data/`:

```
data/
├── results.json         # Все результаты соревнований
├── state.json           # Текущее состояние (для возобновления)
├── models/
│   └── best.pth         # Лучшая модель
└── generated/           # Сгенерированные изображения (опционально)
```

### ❓ Можно ли остановить и продолжить позже?

**Да!** Система автоматически сохраняет состояние после каждого раунда. 

Для возобновления просто запустите команду снова — система продолжит с последнего сохранённого состояния.

### ❓ Как узнать, что модель обучается хорошо?

Смотрите на метрику **accuracy** в логах:
- **< 0.3** — Модель только начала учиться
- **0.3-0.6** — Процесс идёт, но нужны ещё раунды
- **0.6-0.8** — Хороший результат
- **> 0.8** — Отличный результат!

### ❓ Что делать, если accuracy падает?

Это нормально! Учитель намеренно усложняет задачи, фокусируясь на слабых местах. Продолжайте обучение — модель адаптируется.

### ❓ Можно ли использовать GPU?

Да! Система автоматически использует CUDA, если доступен PyTorch с поддержкой GPU.

Проверьте:
```bash
python -c "import torch; print(torch.cuda.is_available())"
```

### ❓ Как посмотреть сгенерированные изображения?

Изображения сохраняются в `data/teacher/round_N/`:
- `XXXXXX.png` — само изображение
- `XXXXXX_mask.png` — маска (если есть)
- `XXXXXX.json` — метаданные (тип искажения, label, etc.)

## Устранение проблем

### Проблема: Ошибка импорта модулей

**Симптомы:**
```
ModuleNotFoundError: No module named 'torch'
```

**Решение:**
```bash
pip install -r requirements.txt --upgrade
```

### Проблема: Недостаточно памяти

**Симптомы:**
```
RuntimeError: CUDA out of memory
```

**Решение:**
- Уменьшите `batch_size` в конфиге или через `--batch-size 16`
- Уменьшите размер задач (`--tasks 20`)
- Закройте другие приложения, использующие GPU

### Проблема: Обучение зависло

**Симптомы:**
- Нет новых логов более 10 минут
- Статус не меняется

**Решение:**
1. Нажмите `Ctrl+C` для остановки
2. Проверьте логи в файле (если указан `--log-file`)
3. Запустите снова — система продолжит с последнего сохранения

### Проблема: Низкая точность (< 0.2) после многих раундов

**Возможные причины:**
- Слишком высокая сложность искажений
- Мало эпох обучения
- Слишком высокий learning rate

**Решение:**
```yaml
# В конфиге уменьшите сложность
teacher:
  adaptation_rate: 0.05  # Было 0.1
  
training:
  epochs: 20             # Было 10
  learning_rate: 0.0005  # Было 0.001
```

### Проблема: API сервер не запускается

**Симптомы:**
```
Address already in use
```

**Решение:**
```bash
# Найти процесс на порту 8000
lsof -i :8000

# Убить процесс
kill -9 <PID>

# Или использовать другой порт
python src/selflearn/run.py --action api --port 8001
```
